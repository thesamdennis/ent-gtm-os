# Roadmap

| Version | Scope | Done when |
|---|---|---|
| **v0.1** (this) | Three skills as instructions, shared contract and schema, synthetic accounts, eval rubric | Skills run in Claude on synthetic accounts |
| v0.2 | Backtest 10 real (local, anonymised) cases; tune play library and fit gate | Radar tiers ≥7/10 correctly, zero fabrication |
| v0.3 | Connectors: email and calendar for last-touch and attendees; documents for notes | Control Tower status computed from real activity |
| v0.4 | Scheduled runs: Monday Radar digest, weekly deal review, T-180 renewal triggers | Runs unattended; seller approves outputs |
| v0.5 | Event triggers (new signal, close-date change, stakeholder change) and a simple dashboard | Agents fire on change, not on a schedule |

## Explicitly not building first

Email writer, meeting summariser, CRM updater, generic sales coach, autonomous SDR. They save time; they don't change who wins strategic accounts.
